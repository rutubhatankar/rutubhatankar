## Featured project

### [Anti-Money Laundering Transaction Detection](https://github.com/rutubhatankar/aml-transaction-detection)
A comparative study benchmarking machine learning, deep learning, and hybrid
ensemble models for detecting suspicious financial transactions in a highly
imbalanced, large-scale dataset. Covers the full pipeline — from class-imbalance
handling and feature engineering through to a "super hybrid" ensemble-of-ensembles
architecture, benchmarked on accuracy, precision, recall, F1, and ROC-AUC.
